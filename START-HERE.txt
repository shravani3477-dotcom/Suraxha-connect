SURAXHA CONNECT - START HERE (no coding tools needed)

1) OPEN IT ON YOUR COMPUTER
   Double-click  index.html  (it opens in Chrome or Edge). That is all.

2) CHANGE THE FACTS (pension amount, bank rates, helplines)
   Right-click  data/rules.js  -> Open with -> Notepad. Edit the text between
   the quote marks, press Ctrl+S, then refresh the browser page.

3) CHANGE THE WORDS ON SCREEN (English / Hindi / Marathi)
   Right-click  app.js -> Open with -> Notepad. The words are at the top,
   inside  en: { ... }   hi: { ... }   mr: { ... }

4) PUT IT ON THE INTERNET (free, permanent link for the examiner)
   Option A: Netlify Drop  -> go to app.netlify.com/drop, make a free account,
             drag the whole  suraxha-connect  folder onto the page.
   Option B: GitHub Pages  -> upload the files to a public repository, then
             Settings -> Pages -> Deploy from a branch -> main -> Save.
   Your link will look like  https://something.netlify.app  or
   https://yourname.github.io/suraxha-connect/

5) TEST THE LINK ON A PHONE
   Android Chrome: menu (3 dots) -> Install app.
   iPhone Safari : Share -> Add to Home Screen.
